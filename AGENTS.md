# AI Working Rules

## Goal

Upgrade Pehnava into a premium informative boutique website.

## Never Change

- Brand colors
- Logo
- Business identity
- Poppins font

## Always Prioritize

1. Performance
2. SEO
3. Accessibility
4. Responsive UI
5. Reusable Angular architecture

## Avoid

- Heavy libraries
- jQuery
- Large animation packages
- Inline styling
- Duplicate components

Every feature must be production ready.
